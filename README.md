# EffectGuard P4 Reviewer Artifact

This is a curated, history-isolated, **development-only** reviewer snapshot of
EffectGuard P4. It contains the source, tests, documentation, and scripts needed
to reproduce one verified service-backed paired witness. It intentionally omits
P3 campaign records, raw traces, databases, generated build outputs, credentials,
and sealed benchmark material.

The branch is not a replacement for the original development history. See
[the research overview](paper/external_review/EFFECTGUARD_EXTERNAL_REVIEW_SUMMARY.md),
[reviewer instructions](paper/reviewer_distribution/REVIEWER_INSTRUCTIONS.md),
[the reproducibility guide](paper/release_candidate/REPRODUCIBILITY_GUIDE.md),
[expected results](paper/release_candidate/EXPECTED_RESULTS.md),
[known limitations](paper/release_candidate/KNOWN_LIMITATIONS.md),
[the security and provenance audit](paper/release_candidate/SECURITY_AND_LICENSE_AUDIT.md),
and the [reviewer-specific technical packages](paper/external_review/).

For history isolation, allowlisted content, and evidence exclusions, read the
[clean-branch audit](paper/reviewer_distribution/CLEAN_BRANCH_AUDIT.md) and
[excluded-evidence notice](paper/reviewer_distribution/EXCLUDED_EVIDENCE_NOTICE.md).
